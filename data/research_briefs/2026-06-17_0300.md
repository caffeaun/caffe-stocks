Our 82-trainer registry has knn_classifier, label_spreading, gaussian_process_classifier, modernnca, qda_classifier — all of which are still *parametric* over a learned similarity / kernel / likelihood. What is missing is a **frozen, randomly-initialized recurrent reservoir with a linear readout** — the Echo State Network family — which generates rich nonlinear temporal features *without any gradient training*. The recent fat-tail bear-regime wins (W6 +311% torch_tabr, +253% torch_scarf, +175% CARD) all came from *magnitude pickers* that score-collapse on bear windows; an ESN's untrained reservoir produces orthogonal high-dimensional features whose readout can be tuned to bear-tolerant linear regions. Yesterday's brief was CARD (denoising-diffusion generative classifier) — picking ESN today is the maximum structural step away from "yet another gradient-trained deep net."

## Recommended technique: Echo State Network (Reservoir Computing) classifier

### Why now
Reservoir computing has had a 2024-2026 renaissance for multivariate time-series classification — IEEE 2024 ([Bianchi et al., reservoir ESN for MTS classification](https://ieeexplore.ieee.org/document/10504130/)) and the May 2025 [Computo Journal tutorial](https://computo-journal.org/published-202505-ferte-reservoirnet/) both report ESNs matching or beating LSTM/Transformer baselines at a fraction of the wall-time, because the recurrent dynamics are *fixed* (only the readout is trained). The 2024 Scientific Reports paper ([Impact of time-history terms on reservoir dynamics](https://www.nature.com/articles/s41598-024-59143-y)) shows that careful spectral-radius / leak-rate tuning lifts non-stationary prediction quality. Our W2/W4 bear-regime walls are largely a feature-collapse problem (linear-decision-boundary trainers stick to the same neighborhood) and a random recurrent projection is exactly the *non-trained, non-collapse-prone* feature generator the loop is missing.

### Scaffold code
```python
# models/trainers.py — append at end (before TRAINERS dict)

import os
import json
import numpy as np
import joblib
from sklearn.linear_model import LogisticRegression


class EchoStateClassifierTrainer(BaseTrainer):
    """Echo State Network — frozen random recurrent reservoir + linear readout.

    Encodes each row's L-step historical sequence panel through a fixed
    randomly-initialized reservoir of `units` leaky-integrator neurons, takes
    the last-step state as a high-dimensional feature vector, concatenates
    it with the tabular features, and fits a logistic-regression readout.
    No backpropagation.
    """

    name = 'esn_classifier'
    consumes_sequences = True

    def __init__(
        self,
        units=500,
        spectral_radius=0.9,
        leak_rate=0.3,
        input_scaling=1.0,
        readout_C=1.0,
        readout_penalty='l2',
        warmup=2,
        pool='last',
        random_state=42,
    ):
        self.units = int(units)
        self.spectral_radius = float(spectral_radius)
        self.leak_rate = float(leak_rate)
        self.input_scaling = float(input_scaling)
        self.readout_C = float(readout_C)
        self.readout_penalty = str(readout_penalty)
        self.warmup = int(warmup)
        self.pool = str(pool)
        self.random_state = int(random_state)
        self._reservoir = None
        self._readout = None
        self._seq_mean = None
        self._seq_std = None

    def _build_reservoir(self):
        from reservoirpy.nodes import Reservoir
        return Reservoir(
            units=self.units,
            sr=self.spectral_radius,
            lr=self.leak_rate,
            input_scaling=self.input_scaling,
            seed=self.random_state,
        )

    def _standardize_seq(self, seq_arr, fit_stats=False):
        # seq_arr: (N, L, C) per-row historical panel
        if fit_stats:
            self._seq_mean = seq_arr.mean(axis=(0, 1), keepdims=True).astype(np.float32)
            std = seq_arr.std(axis=(0, 1), keepdims=True).astype(np.float32)
            std[std < 1e-6] = 1.0
            self._seq_std = std
        return ((seq_arr - self._seq_mean) / self._seq_std).astype(np.float32)

    def _encode(self, seq_arr):
        # seq_arr: (N, L, C) normalized. Returns (N, units).
        N, L, _ = seq_arr.shape
        Z = np.zeros((N, self.units), dtype=np.float32)
        for i in range(N):
            self._reservoir.reset()
            states = self._reservoir.run(seq_arr[i])
            # states: (L, units)
            start = min(self.warmup, max(0, L - 1))
            if self.pool == 'mean':
                Z[i] = states[start:].mean(axis=0)
            else:
                Z[i] = states[-1]
        return Z

    def _coerce_seq(self, X, seq):
        # Accept either an explicit panel (N, L, C) via `seq` kwarg
        # or fall back to a degenerate L=1 panel built from the 2D X.
        if seq is not None:
            arr = np.asarray(seq, dtype=np.float32)
            if arr.ndim == 2:
                arr = arr[:, None, :]
            return arr
        X = np.asarray(X, dtype=np.float32)
        return X.reshape(X.shape[0], 1, X.shape[1])

    def fit(self, X_tr, y_tr, X_val, y_val, **kwargs):
        seq_tr = self._coerce_seq(X_tr, kwargs.get('seq_tr'))
        seq_tr = self._standardize_seq(seq_tr, fit_stats=True)
        self._reservoir = self._build_reservoir()
        Z_tr = self._encode(seq_tr)
        X_tr_arr = np.asarray(X_tr, dtype=np.float32)
        feat = np.concatenate([Z_tr, X_tr_arr], axis=1)
        self._readout = LogisticRegression(
            C=self.readout_C,
            penalty=self.readout_penalty,
            solver='lbfgs' if self.readout_penalty == 'l2' else 'liblinear',
            max_iter=2000,
            random_state=self.random_state,
            n_jobs=-1 if self.readout_penalty == 'l2' else None,
        )
        self._readout.fit(feat, np.asarray(y_tr).astype(np.int64))
        return self

    def predict_proba(self, X, **kwargs):
        seq = self._coerce_seq(X, kwargs.get('seq'))
        seq = self._standardize_seq(seq, fit_stats=False)
        Z = self._encode(seq)
        X_arr = np.asarray(X, dtype=np.float32)
        feat = np.concatenate([Z, X_arr], axis=1)
        proba = self._readout.predict_proba(feat)[:, 1]
        return np.asarray(proba, dtype=np.float32)

    def save(self, model_dir, extra=None):
        os.makedirs(model_dir, exist_ok=True)
        joblib.dump(
            {
                'reservoir': self._reservoir,
                'readout': self._readout,
                'seq_mean': self._seq_mean,
                'seq_std': self._seq_std,
                'config': {
                    'units': self.units,
                    'spectral_radius': self.spectral_radius,
                    'leak_rate': self.leak_rate,
                    'input_scaling': self.input_scaling,
                    'readout_C': self.readout_C,
                    'readout_penalty': self.readout_penalty,
                    'warmup': self.warmup,
                    'pool': self.pool,
                    'random_state': self.random_state,
                },
            },
            os.path.join(model_dir, 'model.joblib'),
        )
        if extra:
            with open(os.path.join(model_dir, 'extra.json'), 'w') as f:
                json.dump(extra, f, indent=2)
```

### Integration notes (for claude_mode)
1. **No GPU required** — the reservoir is pure numpy (via `reservoirpy`) and the readout is sklearn LogisticRegression. CPU-only. Expected wall-time ~3–5 minutes per fold at units=500 over 190k rows, well inside the 30-min budget.
2. **Sequence input is mandatory but defensively fallbacked**: `consumes_sequences=True` means the loop's sequence loader should pass `seq_tr`/`seq_val` (shape `(N, L, C)`) via fit kwargs and `seq` via predict_proba kwargs; if the loader hasn't been wired for this trainer yet, the `_coerce_seq` fallback constructs a degenerate L=1 panel from the 2D features so the trainer still runs (will under-perform until the sequence wiring is in place — surface in the bias diagnostic if all 7 folds collapse to thr=0.0 with no dispersion).
3. **Reservoir is deterministic per `random_state`** — once tuned, results reproduce. The HP sweep should focus on `spectral_radius` × `leak_rate` first (these set the temporal memory horizon — sr near 1.0 = long memory, lr near 0.1 = slow forgetting), then `units` (capacity), then readout penalty/C. Avoid sweeping all axes together per [[fastkan-pos-weight-2-regresses]].
4. **Expected gate behavior**: ESNs historically pick up *short-horizon momentum / regime-shift* signals well. W6 (best historical fat-tail picker home) and W7 (recent torch_sundial-style win) should be the first windows to fire alive thr-sweeps. Bear W2/W4/W5 are the open question — the random projection adds dispersion which *should* help, but spectral_radius needs to be > 0.9 for the reservoir to retain enough context to discriminate sustained-bear vs. mean-reversion bear days.
