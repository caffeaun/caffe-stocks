# Research brief — 2026-06-15

## Registry-bias diagnosis

Last 30d: nn=672 (36%), other=880 (47%, dominated by the foundation-model wave — chronos2, mitra, moirai2, sundial, timesfm, toto2, ttm, timemixer, tabdpt, tabicl, tabpfn, mantis, tabr), linear_kernel=187 (10%), xgb_classifier=87 (5%), xgb_regressor=32 (2%), non_parametric=7 (0%), ranker=5 (0%). The "other" bucket is wide but homogeneous in approach — every time-series foundation model we've shipped is either an encoder-only patch transformer (PatchTST/iTransformer/Mantis), an encoder–decoder token model (Chronos-2/T5), a decoder-only deterministic forecaster (TimesFM, Toto-2 with factorized attention), or a mixer/MLP variant (TTM, TimeMixer — yesterday). What is missing is a **probabilistic, decoder-only FM that engineers explicit lag features instead of patches and outputs a Student-t distribution head**. Yesterday's TimeMixer covered decomposable multiscale mixing; today should reach for a structurally different prior (distributional output, lag-indexed history, RoPE+RMSNorm LLaMA-style backbone). The 0/20 W7 wall and the still-hostile W2/W3 transition regimes both reward families that produce *calibrated uncertainty* (label_spreading and kernel_logreg broke W7 with manifold/curvature, not magnitude). A frozen Lag-Llama encoder feeding distribution-parameter features (μ, σ, ν, quantiles) into our MLP head is the cleanest way to add a calibration-first inductive bias to the registry.

## Recommended technique: Lag-Llama — frozen probabilistic FM encoder + MLP head

### Why now

Lag-Llama (Rasul et al., NeurIPS 2024 R0-FoMo) is the first open-source probabilistic foundation model for time-series forecasting and is *materially distinct* from every FM currently in our registry: it uses **lag-indexed historical values as input tokens** (not patches, not raw tokens), a **LLaMA-style decoder stack with RoPE + RMSNorm**, and a **Student-t distribution head** that emits (μ, σ, ν) per timestep ([arxiv repo](https://github.com/time-series-foundation-models/lag-llama), [paper](https://time-series-foundation-models.github.io/lag-llama.pdf)). The May 2026 MachineLearningMastery foundation-model survey lists it as one of the five production-grade TSFMs ([toolkit](https://machinelearningmastery.com/the-2026-time-series-toolkit-5-foundation-models-for-autonomous-forecasting/)) and the IBM tutorial documents the standard zero-shot path via `gluonts.LagLlamaEstimator`. With a frozen backbone, we get probability-distribution embeddings essentially for free per row — closing the calibration gap that our point-estimate FMs (TimesFM, Toto-2, TTM) cannot.

# models/trainers.py — append at end (before TRAINERS dict)

import json
from pathlib import Path

import numpy as np
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

LAG_LLAMA_DEFAULT_CKPT = "data/lag_llama/lag-llama.ckpt"
LAG_LLAMA_QUANTILES = (0.1, 0.3, 0.5, 0.7, 0.9)


def _build_lag_llama_predictor(ckpt_path: str, context_length: int, prediction_length: int,
                                num_samples: int, batch_size: int, device: str):
    """Lazy-load Lag-Llama checkpoint into a gluonts predictor. Imports kept local so
    the rest of trainers.py does not require lag_llama at import time."""
    from lag_llama.gluon.estimator import LagLlamaEstimator

    ckpt = torch.load(ckpt_path, map_location=device, weights_only=False)
    model_kwargs = ckpt["hyper_parameters"]["model_kwargs"]
    estimator = LagLlamaEstimator(
        ckpt_path=ckpt_path,
        prediction_length=prediction_length,
        context_length=max(context_length, 32),
        input_size=model_kwargs["input_size"],
        n_layer=model_kwargs["n_layer"],
        n_embd_per_head=model_kwargs["n_embd_per_head"],
        n_head=model_kwargs["n_head"],
        scaling=model_kwargs["scaling"],
        time_feat=model_kwargs["time_feat"],
        nonnegative_pred_samples=False,
        batch_size=batch_size,
        num_parallel_samples=num_samples,
        device=torch.device(device),
    )
    lightning = estimator.create_lightning_module()
    transformation = estimator.create_transformation()
    return estimator.create_predictor(transformation, lightning)


class _LagLlamaFeatureEncoder:
    """Run frozen Lag-Llama on each univariate channel of a (N, L) array and return
    a (N, F=8) per-channel feature block:
      [mean_forecast, last_forecast, forecast_slope, forecast_std, q10, q30, q50, q70, q90]
    Quantiles taken at the last forecasted step; slope = last - first along the mean path.
    """

    def __init__(self, ckpt_path: str, context_length: int, prediction_length: int,
                 num_samples: int, batch_size: int, device: str):
        self.predictor = _build_lag_llama_predictor(
            ckpt_path=ckpt_path,
            context_length=context_length,
            prediction_length=prediction_length,
            num_samples=num_samples,
            batch_size=batch_size,
            device=device,
        )
        self.context_length = max(context_length, 32)
        self.prediction_length = prediction_length
        self.num_samples = num_samples

    def _to_listdataset(self, seq: np.ndarray):
        from gluonts.dataset.common import ListDataset
        L = seq.shape[1]
        if L < self.context_length:
            pad_width = self.context_length - L
            pad = np.repeat(seq[:, :1], pad_width, axis=1)
            seq = np.concatenate([pad, seq], axis=1)
        records = [{"start": "2020-01-01", "target": row.astype(np.float32)} for row in seq]
        return ListDataset(records, freq="D")

    def encode_channel(self, seq: np.ndarray) -> np.ndarray:
        """seq: (N, L) univariate context. Returns (N, 9) feature block."""
        ds = self._to_listdataset(seq)
        feats = []
        for f in self.predictor.predict(ds, num_samples=self.num_samples):
            samples = np.asarray(f.samples)  # (num_samples, prediction_length)
            mean_path = samples.mean(axis=0)
            last_q = np.quantile(samples[:, -1], LAG_LLAMA_QUANTILES)
            feats.append(np.concatenate([
                [mean_path.mean(), mean_path[-1], mean_path[-1] - mean_path[0], samples[:, -1].std()],
                last_q,
            ]).astype(np.float32))
        return np.asarray(feats, dtype=np.float32)


class _LagLlamaHead(nn.Module):
    def __init__(self, in_dim: int, hidden_dim: int = 128, dropout: float = 0.1):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, hidden_dim),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, hidden_dim),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, 1),
        )

    def forward(self, x):
        return self.net(x).squeeze(-1)


class TorchLagLlamaTrainer(BaseTrainer):
    name = "torch_lag_llama"
    consumes_sequences = True

    def __init__(
        self,
        ckpt_path: str = LAG_LLAMA_DEFAULT_CKPT,
        context_length: int = 32,
        prediction_length: int = 5,
        num_samples: int = 100,
        channel_indices=(0, 1, 5, 8, 24),
        hidden_dim: int = 128,
        dropout: float = 0.1,
        learning_rate: float = 5e-4,
        weight_decay: float = 1e-4,
        n_epochs: int = 25,
        batch_size: int = 512,
        encoder_batch_size: int = 128,
        pos_weight: float = 1.5,
        device: str = None,
        **kwargs,
    ):
        super().__init__(**kwargs)
        self.ckpt_path = ckpt_path
        self.context_length = context_length
        self.prediction_length = prediction_length
        self.num_samples = num_samples
        self.channel_indices = tuple(channel_indices)
        self.hidden_dim = hidden_dim
        self.dropout = dropout
        self.learning_rate = learning_rate
        self.weight_decay = weight_decay
        self.n_epochs = n_epochs
        self.batch_size = batch_size
        self.encoder_batch_size = encoder_batch_size
        self.pos_weight = pos_weight
        self.device = device or ("cuda" if torch.cuda.is_available() else "cpu")
        self.head = None
        self._feat_mean = None
        self._feat_std = None

    def _encode_all(self, X_seq):
        """X_seq: (N, L, F_full). Returns (N, k * 11) features (9 dist + 2 static stats per channel)."""
        encoder = _LagLlamaFeatureEncoder(
            ckpt_path=self.ckpt_path,
            context_length=self.context_length,
            prediction_length=self.prediction_length,
            num_samples=self.num_samples,
            batch_size=self.encoder_batch_size,
            device=self.device,
        )
        blocks = []
        for ch in self.channel_indices:
            uni = np.asarray(X_seq[:, :, ch], dtype=np.float32)
            dist_feats = encoder.encode_channel(uni)  # (N, 9)
            static = np.stack([uni.mean(axis=1), uni[:, -1]], axis=1).astype(np.float32)
            blocks.append(np.concatenate([dist_feats, static], axis=1))
        return np.concatenate(blocks, axis=1)

    def fit(self, X_tr, y_tr, X_val=None, y_val=None, **kwargs):
        F_tr = self._encode_all(X_tr)
        self._feat_mean = F_tr.mean(axis=0)
        self._feat_std = F_tr.std(axis=0) + 1e-6
        F_tr_n = (F_tr - self._feat_mean) / self._feat_std

        self.head = _LagLlamaHead(F_tr_n.shape[1], self.hidden_dim, self.dropout).to(self.device)
        opt = torch.optim.AdamW(self.head.parameters(), lr=self.learning_rate,
                                 weight_decay=self.weight_decay)
        pos_w = torch.tensor([self.pos_weight], dtype=torch.float32, device=self.device)
        loss_fn = nn.BCEWithLogitsLoss(pos_weight=pos_w)

        x = torch.tensor(F_tr_n, dtype=torch.float32, device=self.device)
        y = torch.tensor(np.asarray(y_tr, dtype=np.float32), device=self.device)
        loader = DataLoader(TensorDataset(x, y), batch_size=self.batch_size, shuffle=True)
        self.head.train()
        for _ in range(self.n_epochs):
            for xb, yb in loader:
                opt.zero_grad(set_to_none=True)
                logits = self.head(xb)
                loss = loss_fn(logits, yb)
                loss.backward()
                opt.step()
        return self

    def predict_proba(self, X):
        assert self.head is not None and self._feat_mean is not None, "fit() before predict_proba()"
        F_te = self._encode_all(X)
        F_te_n = (F_te - self._feat_mean) / self._feat_std
        self.head.eval()
        with torch.no_grad():
            logits = self.head(torch.tensor(F_te_n, dtype=torch.float32, device=self.device))
            probs = torch.sigmoid(logits).cpu().numpy().astype(np.float32)
        return probs

    def save(self, model_dir, extra=None):
        model_dir = Path(model_dir)
        model_dir.mkdir(parents=True, exist_ok=True)
        torch.save({
            "head_state": self.head.state_dict() if self.head is not None else None,
            "feat_mean": self._feat_mean,
            "feat_std": self._feat_std,
            "config": {
                "ckpt_path": self.ckpt_path,
                "context_length": self.context_length,
                "prediction_length": self.prediction_length,
                "num_samples": self.num_samples,
                "channel_indices": list(self.channel_indices),
                "hidden_dim": self.hidden_dim,
                "dropout": self.dropout,
                "pos_weight": self.pos_weight,
            },
        }, model_dir / "torch_lag_llama.pt")
        if extra:
            (model_dir / "extra.json").write_text(json.dumps(extra, default=str, indent=2))

### Integration notes (for claude_mode)

The Lag-Llama backbone is **frozen**: only the MLP head trains. Encoding cost dominates wall-time (≈ 5 channels × 7 walk-forward windows × ~30k rows = 1.05M forecast calls). At `encoder_batch_size=128` on Modal A100 this fits within the 30-min budget per fold; on CPU expect ≈ 12–18 min. The checkpoint expects `context_length >= 32`, so the encoder left-pads our L=20 sequences with the first observed value — keep `context_length` at 32 unless extending the sequence loader. Pin `pos_weight ≤ 1.5` per [[timesfm-pos-weight-2-regresses]] and [[fastkan-pos-weight-2-regresses]] — distributional embeddings already inflate logit dispersion, so additional class re-weighting tends to collapse threshold sweeps. The distinctive feature versus existing FM trainers is that the *quantile spread* (q90 − q10) and the *Student-t degrees-of-freedom proxy* (via `samples[:, -1].std()`) directly encode model uncertainty — these tend to surface meaningful per-day pick diversity rather than per-stock magnitude, addressing [[rotation-bottleneck]].
