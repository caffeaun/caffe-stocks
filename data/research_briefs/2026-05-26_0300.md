# Research brief — 2026-05-26

## Registry-bias diagnosis
Last 30d of 1752 iterations split `other=618 (35%)`, `xgb_classifier=424 (24%)`, `ranker=190 (11%)`, `linear_kernel=188 (11%)`, `nn=139 (8%)`, `xgb_regressor=111 (6%)`, `non_parametric=66 (4%)`, `tree_other=16 (1%)`. Of the 68 registered trainers, the **time-series-foundation-model slot is held by three frozen-backbone members** — `torch_chronos2` (Amazon, value-tokenized encoder-decoder), `torch_timesfm` (Google, patched decoder-only with quantile head), and `torch_time_moe` (sparse MoE decoder). All three are **point/quantile predictors trained with MSE-style losses**; none of them produce a native, full-distribution forecast. That means the W5 / bear-regime wall has never been attacked with a TSFM that explicitly models the *shape* of the next-step return distribution (skew, fat-tail mass, exceedance probability) — every existing TSFM head consumes a median or a fixed grid of quantile estimates. Yesterday's brief (ModernNCA, 2026-05-25) filled the **deep-retrieval / learned-metric** slot, which is structurally orthogonal: an instance-based tabular learner with per-row inference. Today's gap is therefore a **distributional / flow-matching TSFM**, where the head consumes summary statistics of many sampled future-path trajectories rather than a single quantile vector. This is the only TSFM family the loop has not yet seen, and it is the natural complement to ModernNCA's per-row reasoning because it injects *per-row sequence-distribution* signal that engineered tabular features (the 96-dim curated vector) cannot reach.

## Recommended technique: Sundial (Flow-Matching Time-Series Foundation Model, ICML 2025 Oral)

### Why now
Sundial (Liu et al., [arXiv:2502.00816](https://arxiv.org/abs/2502.00816), ICML 2025 Oral) is the first time-series foundation model trained with **flow matching** rather than next-token quantile regression — its `TimeFlow` loss treats each patch's continuous-valued distribution as a vector field learned via Lipman-style flow ODEs, so a single forward pass yields *many* coherent sampled future trajectories rather than a fixed grid of quantile estimates. Pretrained on a 1-trillion-time-point corpus from Tsinghua's group (the same lab that shipped iTransformer and TimesNet), Sundial-base-128M ranks 1st on the GIFT-Eval probabilistic-forecast leaderboard and beats Chronos / TimesFM / Moirai on CRPS at every horizon ([HuggingFace card](https://huggingface.co/thuml/sundial-base-128m); [paper page](https://huggingface.co/papers/2502.00816)). Crucially for us, the sample-trajectory output gives a downstream classifier head access to features that *no existing trainer in our registry can produce*: distribution-shape statistics (mean, std, skew, kurtosis, exceedance-probability at +/- thresholds, inter-quantile spread, max-drawdown across path samples). These are precisely the priors that broke the W5 bear-regime wall when we added monotonic constraints (iter #936) and anomaly-day abstention (iter #1675) — but now derived from a 1T-token pretraining corpus rather than 96 engineered features. The model loads via `transformers.AutoModelForCausalLM` with `trust_remote_code=True`, Apache 2.0 licensed, and sampling latency on GPU is sub-100 ms for the 5-step horizon we need.

# models/trainers.py — append at end (before TRAINERS dict)
import json
import math
from pathlib import Path

import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F


class _SundialPathStatHead(nn.Module):
    """Small MLP head consuming Sundial sample-path statistics + last-step tabular features."""

    def __init__(self, n_stat_features: int, n_tab_features: int,
                 hidden_dim: int = 128, n_layers: int = 2, dropout: float = 0.15):
        super().__init__()
        in_dim = n_stat_features + n_tab_features
        layers: list[nn.Module] = []
        d = in_dim
        for _ in range(n_layers):
            layers += [nn.Linear(d, hidden_dim), nn.GELU(), nn.Dropout(dropout)]
            d = hidden_dim
        layers.append(nn.Linear(d, 1))
        self.net = nn.Sequential(*layers)

    def forward(self, stat_feats: torch.Tensor, tab_feats: torch.Tensor) -> torch.Tensor:
        x = torch.cat([stat_feats, tab_feats], dim=-1)
        return self.net(x).squeeze(-1)


class TorchSundialTrainer(BaseTrainer):
    """Frozen Sundial backbone (flow-matching TS foundation model) + path-stat MLP head.

    Per row we feed Sundial the last `lookback` steps of the chosen channel
    (price-return by default) and generate `num_samples` sample trajectories of length
    `forecast_length`. We summarise these trajectories into a fixed-dim statistic vector
    (mean / std / skew / quantile-spread / exceedance probabilities / sample max-drawdown),
    concatenate with the most-recent tabular features, and feed an MLP classifier head.

    The Sundial backbone is frozen — only the head is trained. Forecasts are cached during
    fit to avoid re-running the backbone every epoch.
    """

    name = 'torch_sundial'
    consumes_sequences = True

    def __init__(self,
                 model_id: str = 'thuml/sundial-base-128m',
                 model_dir: str | None = 'data/sundial_base_128m',
                 channel_index: int = 8,                # close-price return channel; tune in HP search
                 lookback: int = 30,
                 forecast_length: int = 5,
                 num_samples: int = 16,
                 hidden_dim: int = 128,
                 n_head_layers: int = 2,
                 dropout: float = 0.15,
                 learning_rate: float = 1e-3,
                 weight_decay: float = 1e-4,
                 batch_size: int = 512,
                 n_epochs: int = 40,
                 pos_weight: float = 1.3,
                 use_tabular_features: bool = True,
                 inference_batch_size: int = 64,
                 device: str | None = None,
                 seed: int = 1234,
                 **kwargs):
        super().__init__()
        self.model_id = model_id
        self.model_dir = model_dir
        self.channel_index = int(channel_index)
        self.lookback = int(lookback)
        self.forecast_length = int(forecast_length)
        self.num_samples = int(num_samples)
        self.hidden_dim = int(hidden_dim)
        self.n_head_layers = int(n_head_layers)
        self.dropout = float(dropout)
        self.learning_rate = float(learning_rate)
        self.weight_decay = float(weight_decay)
        self.batch_size = int(batch_size)
        self.n_epochs = int(n_epochs)
        self.pos_weight = float(pos_weight)
        self.use_tabular_features = bool(use_tabular_features)
        self.inference_batch_size = int(inference_batch_size)
        self.seed = int(seed)
        self.device = torch.device(device) if device else torch.device(
            'cuda' if torch.cuda.is_available() else 'cpu')
        self.backbone = None
        self.head: _SundialPathStatHead | None = None
        self.n_stat_features = 13          # fixed by _path_stats
        self.tab_dim_: int | None = None

    # ------------- backbone loading & forecast extraction -------------
    def _load_backbone(self):
        if self.backbone is not None:
            return
        from transformers import AutoModelForCausalLM
        src = self.model_dir if (self.model_dir and Path(self.model_dir).exists()) else self.model_id
        self.backbone = AutoModelForCausalLM.from_pretrained(
            src, trust_remote_code=True).to(self.device).eval()
        for p in self.backbone.parameters():
            p.requires_grad_(False)

    @torch.no_grad()
    def _sample_paths(self, seqs: np.ndarray) -> np.ndarray:
        """seqs: (N, lookback) float32 -> (N, num_samples, forecast_length) float32."""
        self._load_backbone()
        out_chunks: list[np.ndarray] = []
        n = seqs.shape[0]
        for i in range(0, n, self.inference_batch_size):
            chunk = torch.from_numpy(seqs[i:i + self.inference_batch_size]).float().to(self.device)
            out = self.backbone.generate(
                chunk,
                max_new_tokens=self.forecast_length,
                num_samples=self.num_samples,
            )
            arr = out.detach().float().cpu().numpy()
            # Some HF wrappers return (B, K, S) or (B, S, K) — coerce to (B, S, K)
            if arr.shape[-1] != self.forecast_length and arr.shape[1] == self.forecast_length:
                arr = arr.transpose(0, 2, 1)
            out_chunks.append(arr)
        return np.concatenate(out_chunks, axis=0).astype(np.float32)

    @staticmethod
    def _path_stats(paths: np.ndarray) -> np.ndarray:
        """paths: (N, S, K) -> (N, 13) summary statistics across S samples and K horizon."""
        # collapse to per-row scalar features
        path_mean = paths.mean(axis=(1, 2))                                            # (N,)
        path_std = paths.std(axis=(1, 2))
        last_mean = paths[:, :, -1].mean(axis=1)                                       # endpoint mean
        last_std = paths[:, :, -1].std(axis=1)
        cumret = paths.sum(axis=2)                                                     # per-sample cumret over K
        p_up = (cumret > 0).mean(axis=1).astype(np.float32)                            # exceedance prob
        p_strong_up = (cumret > 0.02).mean(axis=1).astype(np.float32)
        p_strong_dn = (cumret < -0.02).mean(axis=1).astype(np.float32)
        q25 = np.quantile(cumret, 0.25, axis=1)
        q50 = np.quantile(cumret, 0.50, axis=1)
        q75 = np.quantile(cumret, 0.75, axis=1)
        iqr = q75 - q25
        # per-sample max drawdown across the K-step path, then averaged across samples
        cum = np.cumsum(paths, axis=2)
        running_max = np.maximum.accumulate(cum, axis=2)
        drawdown = (cum - running_max).min(axis=2)
        mdd_mean = drawdown.mean(axis=1)
        skew = ((cumret - cumret.mean(axis=1, keepdims=True)) ** 3).mean(axis=1) / \
               (cumret.std(axis=1) ** 3 + 1e-9)
        stats = np.stack([path_mean, path_std, last_mean, last_std,
                          p_up, p_strong_up, p_strong_dn,
                          q25, q50, q75, iqr, mdd_mean, skew], axis=-1).astype(np.float32)
        return np.nan_to_num(stats, nan=0.0, posinf=0.0, neginf=0.0)

    def _build_inputs(self, X_seq: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
        """X_seq: (N, L, F) -> (stat_feats (N, 13), tab_feats (N, F_or_0))."""
        L = X_seq.shape[1]
        take = min(self.lookback, L)
        seqs = X_seq[:, -take:, self.channel_index]                          # (N, take)
        # zero-pad to self.lookback if needed (Sundial accepts variable but we standardise)
        if take < self.lookback:
            pad = np.zeros((seqs.shape[0], self.lookback - take), dtype=seqs.dtype)
            seqs = np.concatenate([pad, seqs], axis=1)
        paths = self._sample_paths(seqs.astype(np.float32))                  # (N, S, K)
        stats = self._path_stats(paths)                                      # (N, 13)
        tab = X_seq[:, -1, :].astype(np.float32) if self.use_tabular_features else \
            np.zeros((X_seq.shape[0], 0), dtype=np.float32)
        return stats, tab

    # ------------- training -------------
    def fit(self, X_tr, y_tr, X_val, y_val, **kwargs):
        torch.manual_seed(self.seed)
        np.random.seed(self.seed)
        X_tr = np.ascontiguousarray(X_tr)
        X_val = np.ascontiguousarray(X_val)
        y_tr = np.asarray(y_tr).astype(np.float32)
        y_val = np.asarray(y_val).astype(np.float32)

        stat_tr, tab_tr = self._build_inputs(X_tr)
        stat_va, tab_va = self._build_inputs(X_val)
        self.tab_dim_ = tab_tr.shape[1]

        self.head = _SundialPathStatHead(
            n_stat_features=self.n_stat_features,
            n_tab_features=self.tab_dim_,
            hidden_dim=self.hidden_dim,
            n_layers=self.n_head_layers,
            dropout=self.dropout,
        ).to(self.device)

        opt = torch.optim.AdamW(self.head.parameters(),
                                lr=self.learning_rate,
                                weight_decay=self.weight_decay)
        pw = torch.tensor([self.pos_weight], dtype=torch.float32, device=self.device)
        loss_fn = nn.BCEWithLogitsLoss(pos_weight=pw)

        stat_tr_t = torch.from_numpy(stat_tr).to(self.device)
        tab_tr_t = torch.from_numpy(tab_tr).to(self.device)
        y_tr_t = torch.from_numpy(y_tr).to(self.device)
        stat_va_t = torch.from_numpy(stat_va).to(self.device)
        tab_va_t = torch.from_numpy(tab_va).to(self.device)
        y_va_t = torch.from_numpy(y_val).to(self.device)

        n = stat_tr_t.shape[0]
        best_val = float('inf')
        best_state = {k: v.detach().clone() for k, v in self.head.state_dict().items()}
        patience, bad = 6, 0
        for epoch in range(self.n_epochs):
            self.head.train()
            perm = torch.randperm(n, device=self.device)
            for i in range(0, n, self.batch_size):
                idx = perm[i:i + self.batch_size]
                logits = self.head(stat_tr_t[idx], tab_tr_t[idx])
                loss = loss_fn(logits, y_tr_t[idx])
                opt.zero_grad(set_to_none=True)
                loss.backward()
                torch.nn.utils.clip_grad_norm_(self.head.parameters(), max_norm=1.0)
                opt.step()
            self.head.eval()
            with torch.no_grad():
                val_logits = self.head(stat_va_t, tab_va_t)
                val_loss = loss_fn(val_logits, y_va_t).item()
            if val_loss < best_val - 1e-5:
                best_val = val_loss
                best_state = {k: v.detach().clone() for k, v in self.head.state_dict().items()}
                bad = 0
            else:
                bad += 1
                if bad >= patience:
                    break
        self.head.load_state_dict(best_state)
        return self

    # ------------- inference -------------
    @torch.no_grad()
    def predict_proba(self, X) -> np.ndarray:
        assert self.head is not None, 'TorchSundialTrainer not fitted'
        X = np.ascontiguousarray(X)
        stat, tab = self._build_inputs(X)
        self.head.eval()
        logits = self.head(torch.from_numpy(stat).to(self.device),
                           torch.from_numpy(tab).to(self.device))
        return torch.sigmoid(logits).detach().cpu().numpy().astype(np.float32)

    # ------------- persistence -------------
    def save(self, model_dir, extra=None):
        out = Path(model_dir)
        out.mkdir(parents=True, exist_ok=True)
        if self.head is not None:
            torch.save(self.head.state_dict(), out / 'head.pt')
        cfg = {
            'name': self.name,
            'model_id': self.model_id,
            'model_dir': self.model_dir,
            'channel_index': self.channel_index,
            'lookback': self.lookback,
            'forecast_length': self.forecast_length,
            'num_samples': self.num_samples,
            'hidden_dim': self.hidden_dim,
            'n_head_layers': self.n_head_layers,
            'dropout': self.dropout,
            'learning_rate': self.learning_rate,
            'weight_decay': self.weight_decay,
            'pos_weight': self.pos_weight,
            'batch_size': self.batch_size,
            'n_epochs': self.n_epochs,
            'use_tabular_features': self.use_tabular_features,
            'inference_batch_size': self.inference_batch_size,
            'n_stat_features': self.n_stat_features,
            'tab_dim': self.tab_dim_,
            'seed': self.seed,
        }
        (out / 'config.json').write_text(json.dumps(cfg, indent=2))
        if extra:
            (out / 'extra.json').write_text(json.dumps(extra, indent=2, default=str))
        return out

### Integration notes (for claude_mode)
- **Cache the forecasts during fit/predict** — the backbone is frozen, so each `_build_inputs` call dominates runtime; the implementation already does one pass per fit and one per predict (no per-epoch regeneration). With L=30, K=5, S=16 and `inference_batch_size=64`, expect ~6-8 sec/1000 rows on a single V100 → ~3 min total per window. That fits comfortably inside the 30-min iteration budget across 7 windows.
- **Pin `pos_weight ≤ 1.5`** — memory `feedback_timesfm_pos_weight_2_regresses.md` showed every TSFM-head trainer collapses the threshold sweep at `pos_weight ≥ 2.0`; Sundial's distributional output is even more sensitive because the sample-stat features are already monotonic in the up/down probability.
- **Channel index** — pick the channel that is *return-like* (zero-centered, mean-reverting). Per memory `feedback_timesfm_breaks_w1_w5.md`, channels 7-9 (`ret_1d`-family) gave per-stock dispersion for TimesFM; start at `channel_index=8` and sweep ∈ {7, 8, 9}.
- **No-weights run** — if the local `data/sundial_base_128m/` directory is missing, the trainer falls back to `from_pretrained('thuml/sundial-base-128m', trust_remote_code=True)`, which will download (~250 MB) on first invocation. The post-script's `huggingface-cli download` step is therefore an optimisation, not a hard requirement.
- **Expected gate behaviour** — flow-matching distributional features should help most on **W5** (bear regime, where exceedance-probability skews towards down) and **W2-W3** (transition regimes, where IQR widens dramatically). Expect threshold sweep to remain alive across all 7 windows (no collapse) because the sample-path features are bounded in [0, 1] for the probability stats.
