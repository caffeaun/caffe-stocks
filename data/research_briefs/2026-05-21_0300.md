# Research brief — 2026-05-21

## Registry-bias diagnosis
Last 30d the loop spent 28% of iterations on xgb_classifier, 12% on rankers, 12% on linear/kernel, 9% on neural nets, 7% on xgb_regressor and only 4% on non-parametric models. Across 60 registered trainers, the **frequency-domain / spectral inductive bias is entirely absent** — every neural family we have (GRU, Transformer, iTransformer, PatchTST, Mamba, TabM, TabNet, Chronos-2, Time-MoE, attentive MLP) processes the L=20-day window in the *time* domain. Tree families slice by feature thresholds, kernel families project to RBF features. Nothing in the registry can natively express "this stock's weekly-cycle phase" or "cross-channel breadth-spectrum interference," which is exactly the signal class hypothesized to differentiate transition windows W2–W4 (where saturation is loudest). Yesterday's pick (Chronos-2 frozen-encoder head) is also a transformer-backbone TSFM, so re-trying any transformer or any TSFM-with-frozen-head violates the structural-difference rule.

## Recommended technique: FreTS — Frequency-domain MLP classifier (cross-channel + cross-time spectral mixing)

### Why now
FreTS (Yi et al., NeurIPS 2023) showed that DFT + per-frequency MLPs on real/imag parts beat both Transformer and TSMixer baselines on 13 forecasting benchmarks while remaining tiny (~25k params at our config), and the line of work has only gotten stronger: FilterNet (same group, late 2024) extends the family with learnable frequency filters, and a 2025 NeurIPS-style "Frequency-domain MLPs are More Effective Learners" follow-up positions the spectral-MLP family as the preferred light-weight alternative to attention. Crucially, FreTS trains **from scratch on our data** — it is not a foundation model, not pretrained, has no checkpoint dependency, and brings a fundamentally different inductive bias (per-frequency-bin complex-valued mixing across both channel and time axes) than the transformer/SSM/kernel families we have saturated. References: https://arxiv.org/abs/2311.06184 (paper), https://github.com/aikunyi/FreTS (code).

# models/trainers.py — append at end (before TRAINERS dict)

import os
import json
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader, TensorDataset


def _frets_complex_linear(z, W_r, W_i, b_r, b_i):
    """Complex-valued linear: y = (W_r + jW_i) @ z + (b_r + jb_i),
    with ReLU applied to real and imaginary parts separately."""
    z_r, z_i = z.real, z.imag
    y_r = F.relu(z_r @ W_r - z_i @ W_i + b_r)
    y_i = F.relu(z_r @ W_i + z_i @ W_r + b_i)
    return torch.complex(y_r, y_i)


class _FreTSNet(nn.Module):
    """Frequency-domain MLP classifier inspired by FreTS (NeurIPS 2023).
    Input: (B, L, C) sequences. Architecture:
      embed scalar -> E-dim
      FFT along channel axis -> complex MLP -> iFFT  (Frequency Channel Learner)
      FFT along time axis    -> complex MLP -> iFFT  (Frequency Temporal Learner)
      mean-pool over (L, C) -> head -> logit
    """
    def __init__(self, seq_len, channels, embed_size=64, hidden_size=128, dropout=0.1):
        super().__init__()
        self.seq_len = int(seq_len)
        self.channels = int(channels)
        self.embed_size = int(embed_size)
        self.embed = nn.Linear(1, self.embed_size)
        scale = 1.0 / float(np.sqrt(self.embed_size))
        E = self.embed_size
        self.Wc_r = nn.Parameter(torch.randn(E, E) * scale)
        self.Wc_i = nn.Parameter(torch.randn(E, E) * scale)
        self.bc_r = nn.Parameter(torch.zeros(E))
        self.bc_i = nn.Parameter(torch.zeros(E))
        self.Wt_r = nn.Parameter(torch.randn(E, E) * scale)
        self.Wt_i = nn.Parameter(torch.randn(E, E) * scale)
        self.bt_r = nn.Parameter(torch.zeros(E))
        self.bt_i = nn.Parameter(torch.zeros(E))
        self.head = nn.Sequential(
            nn.LayerNorm(E),
            nn.Linear(E, int(hidden_size)),
            nn.GELU(),
            nn.Dropout(float(dropout)),
            nn.Linear(int(hidden_size), 1),
        )

    def forward(self, x):
        B, L, C = x.shape
        x = x.unsqueeze(-1)
        x = self.embed(x)
        z = torch.fft.rfft(x, dim=2)
        z = _frets_complex_linear(z, self.Wc_r, self.Wc_i, self.bc_r, self.bc_i)
        x = torch.fft.irfft(z, n=C, dim=2)
        z = torch.fft.rfft(x, dim=1)
        z = _frets_complex_linear(z, self.Wt_r, self.Wt_i, self.bt_r, self.bt_i)
        x = torch.fft.irfft(z, n=L, dim=1)
        pooled = x.mean(dim=(1, 2))
        logit = self.head(pooled).squeeze(-1)
        return logit


class TorchFreTSTrainer(BaseTrainer):
    name = 'torch_frets'
    consumes_sequences = True

    def __init__(self, embed_size=64, hidden_size=128, dropout=0.1,
                 learning_rate=1e-3, weight_decay=1e-4, pos_weight=1.5,
                 epochs=20, batch_size=256, device=None, seed=42, **kwargs):
        self.embed_size = int(embed_size)
        self.hidden_size = int(hidden_size)
        self.dropout = float(dropout)
        self.learning_rate = float(learning_rate)
        self.weight_decay = float(weight_decay)
        self.pos_weight = float(pos_weight)
        self.epochs = int(epochs)
        self.batch_size = int(batch_size)
        self.device = device or ('cuda' if torch.cuda.is_available() else 'cpu')
        self.seed = int(seed)
        self.model = None
        self.seq_len = None
        self.channels = None

    def _build_model(self, seq_len, channels):
        torch.manual_seed(self.seed)
        m = _FreTSNet(seq_len=seq_len, channels=channels,
                      embed_size=self.embed_size, hidden_size=self.hidden_size,
                      dropout=self.dropout)
        return m.to(self.device)

    @staticmethod
    def _as_tensor_X(X):
        arr = np.asarray(X, dtype=np.float32)
        return torch.from_numpy(arr)

    def fit(self, X_tr, y_tr, X_val=None, y_val=None, **kwargs):
        X_t = self._as_tensor_X(X_tr)
        if X_t.ndim != 3:
            raise ValueError(f"TorchFreTSTrainer expects (N, L, C) sequences, got {tuple(X_t.shape)}")
        N, L, C = X_t.shape
        self.seq_len, self.channels = int(L), int(C)
        y_t = torch.from_numpy(np.asarray(y_tr, dtype=np.float32).reshape(-1))
        self.model = self._build_model(L, C)
        ds = TensorDataset(X_t, y_t)
        loader = DataLoader(ds, batch_size=self.batch_size, shuffle=True, drop_last=False)
        opt = torch.optim.AdamW(self.model.parameters(),
                                lr=self.learning_rate,
                                weight_decay=self.weight_decay)
        pos_w = torch.tensor([float(self.pos_weight)], device=self.device)
        loss_fn = nn.BCEWithLogitsLoss(pos_weight=pos_w)
        self.model.train()
        for _ep in range(self.epochs):
            for xb, yb in loader:
                xb = xb.to(self.device, non_blocking=True)
                yb = yb.to(self.device, non_blocking=True)
                logit = self.model(xb)
                loss = loss_fn(logit, yb)
                opt.zero_grad()
                loss.backward()
                torch.nn.utils.clip_grad_norm_(self.model.parameters(), max_norm=1.0)
                opt.step()
        self.model.eval()
        return self

    @torch.no_grad()
    def predict_proba(self, X):
        if self.model is None:
            raise RuntimeError("TorchFreTSTrainer.predict_proba called before fit")
        X_t = self._as_tensor_X(X)
        if X_t.ndim != 3:
            raise ValueError(f"TorchFreTSTrainer expects (N, L, C) sequences, got {tuple(X_t.shape)}")
        out = []
        bs = max(int(self.batch_size), 1)
        self.model.eval()
        for i in range(0, X_t.shape[0], bs):
            xb = X_t[i:i + bs].to(self.device)
            logit = self.model(xb)
            p = torch.sigmoid(logit).detach().cpu().numpy().astype(np.float32)
            out.append(p)
        return np.concatenate(out, axis=0)

    def save(self, model_dir, extra=None):
        os.makedirs(model_dir, exist_ok=True)
        ckpt = {
            'state_dict': (self.model.state_dict() if self.model is not None else None),
            'seq_len': self.seq_len,
            'channels': self.channels,
            'hparams': {
                'embed_size': self.embed_size,
                'hidden_size': self.hidden_size,
                'dropout': self.dropout,
                'learning_rate': self.learning_rate,
                'weight_decay': self.weight_decay,
                'pos_weight': self.pos_weight,
                'epochs': self.epochs,
                'batch_size': self.batch_size,
                'seed': self.seed,
            },
        }
        torch.save(ckpt, os.path.join(model_dir, 'torch_frets.pt'))
        meta = {'name': self.name, 'consumes_sequences': self.consumes_sequences}
        if extra:
            meta.update(extra)
        with open(os.path.join(model_dir, 'meta.json'), 'w') as f:
            json.dump(meta, f, indent=2)
        return model_dir

### Integration notes (for claude_mode)
This trainer reuses the existing sequence loader (consumes_sequences=True, expects (N, L=20, C=96) batches) — no changes to `sequence_loader.py` needed. The full model is ~25k params at default HPs, so CPU training is viable and a full 7-window fold should finish in well under 5 minutes on GPU and under 20 minutes on CPU — leaving plenty of slack inside the 30-min budget for HP sweeps. Two implementation watch-outs: (1) `torch.fft.rfft` and `torch.fft.irfft` are autograd-friendly and need no special build flags but require PyTorch ≥ 1.8 (we already have ≥ 2.x); (2) the complex-valued MLP uses real-storage tensors via `torch.complex(...)` — if the kernel is run on certain older CUDA stacks complex backward can be slow, in which case set `device='cpu'` for the first iteration to confirm correctness. The model is initialised with a 1/√E init scale so the default LR=1e-3 already converges; do not LR-warmup. Output is a sigmoid probability per row in (N,) shape, matching the existing predict_proba contract.
