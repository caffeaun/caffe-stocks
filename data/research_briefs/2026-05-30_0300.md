Last-30d distribution (1949 iters): other=779 (40%), xgb_classifier=455 (23%),
ranker=190 (10%), linear_kernel=188 (10%), nn=144 (7%), xgb_regressor=111 (6%),

entire deep-learning universe of architectures — is the smallest substantive
bucket (7%). Within that NN slice, every existing sequence-aware trainer
(`torch_seq_transformer`, `torch_patchtst`, `torch_frets`, `torch_seq_gru*`,
`torch_xlstm`, plus the foundation-model wrappers `torch_chronos2`,
`torch_timesfm`, `torch_sundial`, `torch_time_moe`) tokenizes along the **time
axis** (patches, lags, time steps) and treats each of the 96 features either as
an independent channel (PatchTST-style) or stacks them into a wide hidden
representation. Nothing in the registry explicitly tokenizes along the
**variate axis** so that attention captures cross-feature interactions between
the 96 indicators directly. Yesterday's brief was FastKAN (local
Gaussian-RBF interpolation over flat features) — a pure inductive-bias mismatch
relative to what is missing: explicit variate-to-variate attention.

## Recommended technique: iTransformer (Inverted Transformer for Multivariate Time Series)

### Why now
iTransformer (Liu et al., ICLR 2024 Spotlight; thuml official) reverses the
standard Transformer tokenization: each VARIATE becomes a token, the time
dimension is folded into the per-token embedding via MLP, and self-attention
runs across variates so the model learns explicit pair-wise interactions
between the 96 features. The 2026 GIFT-Eval / TSFM benchmark survey reports
that fine-tuned PatchTST + iTransformer still win on multivariate benchmarks
where foundation models lag, particularly when cross-channel interactions
dominate signal — exactly our regime, where breadth × regime × technical
indicators co-move. Lucidrains maintains a `pip install iTransformer` PyPI
package (MIT) and the architecture trains from scratch on 190k rows in well
under our 30-minute budget. References:
[thuml/iTransformer](https://github.com/thuml/iTransformer),
[lucidrains/iTransformer](https://github.com/lucidrains/iTransformer).

# models/trainers.py — append at end (before TRAINERS dict)
import json
from pathlib import Path

import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset


class _ITransformerClassifier(nn.Module):
    """Wraps lucidrains' iTransformer encoder with a binary classification head.

    Input:  (B, T, V) where V = number of features (variates) and T = lookback.
    Output: (B,) logits.
    """

    def __init__(self, num_variates, lookback_len, dim, depth, heads, dim_head, dropout):
        super().__init__()
        from iTransformer import iTransformer

        self.backbone = iTransformer(
            num_variates=num_variates,
            lookback_len=lookback_len,
            dim=dim,
            depth=depth,
            heads=heads,
            dim_head=dim_head,
            pred_length=1,
            use_reversible_instance_norm=True,
        )
        self.head = nn.Sequential(
            nn.Dropout(dropout),
            nn.Linear(num_variates, 1),
        )

    def forward(self, x):
        preds = self.backbone(x)
        feat = preds[1].squeeze(1)
        return self.head(feat).squeeze(-1)


class TorchITransformerTrainer(BaseTrainer):
    name = 'torch_itransformer'
    consumes_sequences = True

    def __init__(self, **kwargs):
        self.dim = int(kwargs.get('dim', 128))
        self.depth = int(kwargs.get('depth', 3))
        self.heads = int(kwargs.get('heads', 4))
        self.dim_head = int(kwargs.get('dim_head', 32))
        self.dropout = float(kwargs.get('dropout', 0.1))
        self.lr = float(kwargs.get('learning_rate', 1e-3))
        self.weight_decay = float(kwargs.get('weight_decay', 1e-4))
        self.batch_size = int(kwargs.get('batch_size', 256))
        self.max_epochs = int(kwargs.get('max_epochs', 30))
        self.early_stop_patience = int(kwargs.get('early_stop_patience', 5))
        self.pos_weight = float(kwargs.get('pos_weight', 1.5))
        self.grad_clip = float(kwargs.get('grad_clip', 1.0))
        self.seed = int(kwargs.get('seed', 42))
        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
        self.model = None
        self.num_variates = None
        self.lookback_len = None

    def _to_3d(self, X):
        X = np.asarray(X)
        if X.ndim == 2:
            return X[:, None, :].astype(np.float32)
        if X.ndim == 3:
            return X.astype(np.float32)
        raise ValueError(f"unexpected X shape {X.shape}")

    def fit(self, X_tr, y_tr, X_val=None, y_val=None, **kwargs):
        torch.manual_seed(self.seed)
        np.random.seed(self.seed)

        X_tr = self._to_3d(X_tr)
        y_tr = np.asarray(y_tr).astype(np.float32).ravel()

        n_samples, lookback, n_var = X_tr.shape
        self.lookback_len = lookback
        self.num_variates = n_var

        self.model = _ITransformerClassifier(
            num_variates=n_var,
            lookback_len=lookback,
            dim=self.dim,
            depth=self.depth,
            heads=self.heads,
            dim_head=self.dim_head,
            dropout=self.dropout,
        ).to(self.device)

        pos_w = torch.tensor([self.pos_weight], device=self.device)
        loss_fn = nn.BCEWithLogitsLoss(pos_weight=pos_w)
        opt = optim.AdamW(
            self.model.parameters(),
            lr=self.lr,
            weight_decay=self.weight_decay,
        )

        ds_tr = TensorDataset(torch.from_numpy(X_tr), torch.from_numpy(y_tr))
        dl_tr = DataLoader(ds_tr, batch_size=self.batch_size, shuffle=True, drop_last=False)

        has_val = X_val is not None and y_val is not None and len(X_val) > 0
        if has_val:
            X_val = self._to_3d(X_val)
            y_val = np.asarray(y_val).astype(np.float32).ravel()
            ds_va = TensorDataset(torch.from_numpy(X_val), torch.from_numpy(y_val))
            dl_va = DataLoader(ds_va, batch_size=self.batch_size, shuffle=False)

        best_val = float('inf')
        best_state = None
        bad = 0
        for _ in range(self.max_epochs):
            self.model.train()
            for xb, yb in dl_tr:
                xb = xb.to(self.device, non_blocking=True)
                yb = yb.to(self.device, non_blocking=True)
                opt.zero_grad()
                logits = self.model(xb)
                loss = loss_fn(logits, yb)
                loss.backward()
                if self.grad_clip > 0:
                    torch.nn.utils.clip_grad_norm_(self.model.parameters(), self.grad_clip)
                opt.step()

            if has_val:
                self.model.eval()
                losses = []
                with torch.no_grad():
                    for xb, yb in dl_va:
                        xb = xb.to(self.device, non_blocking=True)
                        yb = yb.to(self.device, non_blocking=True)
                        logits = self.model(xb)
                        losses.append(loss_fn(logits, yb).item())
                val_loss = float(np.mean(losses)) if losses else float('inf')
                if val_loss < best_val - 1e-5:
                    best_val = val_loss
                    bad = 0
                    best_state = {
                        k: v.detach().cpu().clone()
                        for k, v in self.model.state_dict().items()
                    }
                else:
                    bad += 1
                    if bad >= self.early_stop_patience:
                        break

        if best_state is not None:
            self.model.load_state_dict(best_state)
        return self

    def predict_proba(self, X):
        X = self._to_3d(X)
        self.model.eval()
        chunks = []
        bs = self.batch_size
        with torch.no_grad():
            for i in range(0, len(X), bs):
                xb = torch.from_numpy(X[i:i + bs]).to(self.device)
                logits = self.model(xb)
                chunks.append(torch.sigmoid(logits).cpu().numpy())
        return np.concatenate(chunks)

    def save(self, model_dir, extra=None):
        model_dir = Path(model_dir)
        model_dir.mkdir(parents=True, exist_ok=True)
        if self.model is not None:
            torch.save(
                {
                    'state_dict': self.model.state_dict(),
                    'num_variates': self.num_variates,
                    'lookback_len': self.lookback_len,
                    'hparams': {
                        'dim': self.dim,
                        'depth': self.depth,
                        'heads': self.heads,
                        'dim_head': self.dim_head,
                        'dropout': self.dropout,
                        'pos_weight': self.pos_weight,
                    },
                },
                model_dir / 'model.pt',
            )
        if extra:
            (model_dir / 'extra.json').write_text(json.dumps(extra, default=str, indent=2))

### Integration notes (for claude_mode)
- `consumes_sequences = True`: the sequence loader will feed `(B, T, F)` tensors
  where T is the lookback window (e.g. 20 trading days) and F=96 is the feature
  count. iTransformer treats each of the 96 features as a token, so attention
  is `O(F^2) = O(96^2)` per layer — cheap. With `depth=3, dim=128, heads=4`
  the model fits comfortably in CPU/GPU memory and trains 30 epochs over 190k
  rows in well under 30 minutes on a single GPU.
- Reversible instance-norm is enabled (`use_reversible_instance_norm=True`).
  Do NOT re-normalize features upstream — it conflicts with the package's
  internal RevIN.
- The lucidrains package returns `Dict[int, Tensor(B, pred_length, V)]` keyed
  by prediction lengths; we configure `pred_length=1` so the dict has a single
  key `1`. The head linearly projects the V variate-scores down to a logit.
- Score-distribution expectation: explicit variate attention tends to produce
  sharper score dispersion than PatchTST/FreTS on bear-regime days, because
  the cross-feature interaction picks up regime-by-breadth conjunctions. This
  family should be sweep-alive on W3/W5/W6 (the bear/transition walls). Pin
  `pos_weight ∈ [1.2, 1.8]` on first sweep — both `torch_frets` and
  `torch_timesfm` collapsed the threshold sweep at `pos_weight ≥ 2.0`
  (memory: `feedback_torch_frets_low_posweight_collapses_scores`,
  `feedback_timesfm_pos_weight_2_regresses`).
