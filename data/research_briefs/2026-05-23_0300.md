## Recommended technique: TimesFM-2.5 (Google patched decoder-only TS foundation model) — frozen-backbone quantile-forecast embeddings + classification head

### Why now
TimesFM-2.5-200M shipped in November 2025 on HuggingFace ([google/timesfm-2.5-200m-pytorch](https://huggingface.co/google/timesfm-2.5-200m-pytorch)) with two architecturally important changes vs. TimesFM-1.0: a **continuous quantile head** (10 quantile outputs per horizon step, not a tokenized softmax) and a **flip-invariance + positivity-aware** inference path that stabilizes the model on financial-style series with regime sign-flips. Crucially TimesFM uses **input patching with a decoder-only attention model** — a fundamentally different mapping from Chronos-2's **discrete value-token encoder** (Chronos quantizes raw values to a vocabulary, TimesFM keeps them continuous and patches them); the two encode the same input differently and the resulting quantile distributions are independently informative. The November 2025 GIFT-Eval refresh ([MachineLearningMastery 2026 Time Series Toolkit](https://machinelearningmastery.com/the-2026-time-series-toolkit-5-foundation-models-for-autonomous-forecasting/)) ranks TimesFM-2.5 in the top tier alongside Chronos-2 and Moirai-2 across 97 task configurations / 55 datasets — meaning the **forecast quantiles it returns are calibrated enough to be used as features**, not just point predictions. For our problem the inductive prior is: feeding TimesFM the last L days of one channel (e.g., log-return) returns an 11-dim summary (1 point forecast + 10 quantiles) whose **dispersion encodes regime-conditional uncertainty** — a signal our engineered features approximate only via hand-rolled volatility ratios. Concatenating that 11-dim summary with the existing 96 engineered features and training a small MLP head on top is the standard frozen-backbone transfer pattern, runs in CPU/GPU in the 30-min budget (forward-only inference, no fine-tuning), and lets the day-gate / ranker layer downstream see a new information channel without rewriting upstream feature engineering.

# models/trainers.py — append at end (before TRAINERS dict)

import os
import json
import numpy as np
import torch
import torch.nn as nn


class _TimesFMHead(nn.Module):
    """Small MLP head over [tabular_last_step ‖ timesfm_forecast_embedding]."""

    def __init__(self, in_dim, hidden, dropout):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, hidden),
            nn.GELU(),
            nn.Dropout(float(dropout)),
            nn.Linear(hidden, hidden),
            nn.GELU(),
            nn.Dropout(float(dropout)),
            nn.Linear(hidden, 1),
        )

    def forward(self, x):
        return self.net(x).squeeze(-1)


class TorchTimesFMTrainer(BaseTrainer):
    """Frozen TimesFM-2.5 backbone as zero-shot quantile-forecast feature extractor.

    Pipeline per sample:
      1. Take sequence X[i] of shape (L, C) where C = num engineered features per step.
      2. Pick one channel (channel_index, default -1 = last column) as univariate input
         to TimesFM, yielding point_forecast (horizon,) + quantile_forecast (horizon, 10).
      3. Flatten the (horizon, 11) forecast tensor into an 11*horizon-dim embedding.
      4. Concatenate with the last-step tabular row X[i, -1, :] -> (C + 11*horizon)-dim.
      5. Feed to a small MLP head trained with BCEWithLogitsLoss (pos_weight optional).
    The TimesFM backbone is loaded once, kept in eval()+no_grad, and reused for
    fit() and predict_proba(). Only the MLP head is trained.
    """

    name = 'torch_timesfm'
    consumes_sequences = True

    def __init__(self, model_id='google/timesfm-2.5-200m-pytorch',
                 horizon=1, channel_index=-1, head_hidden=128,
                 dropout=0.15, learning_rate=1e-3, weight_decay=1e-4,
                 pos_weight=1.5, epochs=30, batch_size=512,
                 inference_batch=64, patience=5, device=None, seed=42,
                 max_context=512, **kwargs):
        self.model_id = str(model_id)
        self.horizon = int(horizon)
        self.channel_index = int(channel_index)
        self.head_hidden = int(head_hidden)
        self.dropout = float(dropout)
        self.learning_rate = float(learning_rate)
        self.weight_decay = float(weight_decay)
        self.pos_weight = float(pos_weight)
        self.epochs = int(epochs)
        self.batch_size = int(batch_size)
        self.inference_batch = int(inference_batch)
        self.patience = int(patience)
        self.device = device or ('cuda' if torch.cuda.is_available() else 'cpu')
        self.seed = int(seed)
        self.max_context = int(max_context)
        self._tfm = None
        self.head = None
        self._scaler_mean = None
        self._scaler_std = None
        self.in_dim = None

    def _load_backbone(self):
        if self._tfm is not None:
            return
        import timesfm
        tfm = timesfm.TimesFM_2p5_200M_torch.from_pretrained(self.model_id)
        tfm.compile(timesfm.ForecastConfig(
            max_context=max(self.max_context, 1024),
            max_horizon=max(self.horizon, 256),
            normalize_inputs=True,
            use_continuous_quantile_head=True,
            force_flip_invariance=True,
            infer_is_positive=False,
            fix_quantile_crossing=True,
        ))
        self._tfm = tfm

    @staticmethod
    def _as_3d(X):
        arr = np.asarray(X, dtype=np.float32)
        if arr.ndim != 3:
            raise ValueError(
                f"TorchTimesFMTrainer expects (N, L, C) sequences, got {tuple(arr.shape)}"
            )
        return arr

    def _encode(self, X_3d):
        """Run TimesFM forecast on one channel of each sample. Returns (N, 11*horizon)."""
        self._load_backbone()
        N, L, C = X_3d.shape
        ci = self.channel_index if self.channel_index >= 0 else (C + self.channel_index)
        ci = max(0, min(int(ci), C - 1))
        out_chunks = []
        for i in range(0, N, self.inference_batch):
            j = min(N, i + self.inference_batch)
            inputs = [X_3d[k, :, ci].astype(np.float32) for k in range(i, j)]
            point_fc, quant_fc = self._tfm.forecast(
                horizon=self.horizon,
                inputs=inputs,
            )
            pf = np.asarray(point_fc, dtype=np.float32).reshape(j - i, self.horizon, 1)
            qf = np.asarray(quant_fc, dtype=np.float32).reshape(j - i, self.horizon, -1)
            emb = np.concatenate([pf, qf], axis=2).reshape(j - i, -1)
            out_chunks.append(emb)
        return np.concatenate(out_chunks, axis=0)

    @staticmethod
    def _stack_features(X_3d, emb):
        last = X_3d[:, -1, :].astype(np.float32)
        finite_emb = np.nan_to_num(emb, nan=0.0, posinf=0.0, neginf=0.0)
        return np.concatenate([last, finite_emb], axis=1)

    def _fit_scaler(self, F):
        self._scaler_mean = F.mean(axis=0).astype(np.float32)
        self._scaler_std = (F.std(axis=0) + 1e-6).astype(np.float32)

    def _apply_scaler(self, F):
        return ((F - self._scaler_mean) / self._scaler_std).astype(np.float32)

    def fit(self, X_tr, y_tr, X_val=None, y_val=None, **kwargs):
        torch.manual_seed(self.seed)
        np.random.seed(self.seed)
        X_tr_3d = self._as_3d(X_tr)
        emb_tr = self._encode(X_tr_3d)
        F_tr = self._stack_features(X_tr_3d, emb_tr)
        self._fit_scaler(F_tr)
        F_tr = self._apply_scaler(F_tr)
        self.in_dim = int(F_tr.shape[1])

        has_val = (X_val is not None) and (y_val is not None) and len(y_val) > 0
        if has_val:
            X_val_3d = self._as_3d(X_val)
            emb_val = self._encode(X_val_3d)
            F_val = self._apply_scaler(self._stack_features(X_val_3d, emb_val))
            yv_t = torch.from_numpy(np.asarray(y_val, dtype=np.float32).reshape(-1)).to(self.device)
            Fv_t = torch.from_numpy(F_val).to(self.device)
        else:
            yv_t = None
            Fv_t = None

        self.head = _TimesFMHead(self.in_dim, self.head_hidden, self.dropout).to(self.device)
        opt = torch.optim.AdamW(
            self.head.parameters(),
            lr=self.learning_rate, weight_decay=self.weight_decay,
        )
        pos_w = torch.tensor([float(self.pos_weight)], device=self.device)
        loss_fn = nn.BCEWithLogitsLoss(pos_weight=pos_w)

        Ftr_t = torch.from_numpy(F_tr).to(self.device)
        ytr_t = torch.from_numpy(np.asarray(y_tr, dtype=np.float32).reshape(-1)).to(self.device)

        best_val = float('inf')
        best_state = None
        bad = 0
        N = Ftr_t.size(0)
        for _ep in range(self.epochs):
            self.head.train()
            perm = torch.randperm(N, device=self.device)
            for i in range(0, N, self.batch_size):
                idx = perm[i:i + self.batch_size]
                logit = self.head(Ftr_t[idx])
                loss = loss_fn(logit, ytr_t[idx])
                opt.zero_grad()
                loss.backward()
                torch.nn.utils.clip_grad_norm_(self.head.parameters(), 1.0)
                opt.step()
            if has_val:
                self.head.eval()
                with torch.no_grad():
                    vlogit = self.head(Fv_t)
                    vloss = loss_fn(vlogit, yv_t).item()
                if vloss < best_val - 1e-4:
                    best_val = vloss
                    best_state = {k: v.detach().clone() for k, v in self.head.state_dict().items()}
                    bad = 0
                else:
                    bad += 1
                    if bad >= self.patience:
                        break
        if best_state is not None:
            self.head.load_state_dict(best_state)
        self.head.eval()
        return self

    @torch.no_grad()
    def predict_proba(self, X):
        if self.head is None:
            raise RuntimeError("TorchTimesFMTrainer.predict_proba called before fit")
        X_3d = self._as_3d(X)
        emb = self._encode(X_3d)
        F = self._apply_scaler(self._stack_features(X_3d, emb))
        out = []
        bs = max(int(self.batch_size), 1)
        self.head.eval()
        for i in range(0, F.shape[0], bs):
            xb = torch.from_numpy(F[i:i + bs]).to(self.device)
            logit = self.head(xb)
            p = torch.sigmoid(logit).detach().cpu().numpy().astype(np.float32)
            out.append(p)
        return np.concatenate(out, axis=0)

    def save(self, model_dir, extra=None):
        os.makedirs(model_dir, exist_ok=True)
        state_path = os.path.join(model_dir, 'timesfm_head_state.pt')
        torch.save({
            'head_state': self.head.state_dict() if self.head is not None else None,
            'scaler_mean': self._scaler_mean,
            'scaler_std': self._scaler_std,
            'in_dim': self.in_dim,
            'head_hidden': self.head_hidden,
            'dropout': self.dropout,
            'horizon': self.horizon,
            'channel_index': self.channel_index,
            'model_id': self.model_id,
        }, state_path)
        meta = {
            'name': self.name,
            'model_id': self.model_id,
            'horizon': self.horizon,
            'channel_index': self.channel_index,
            'head_hidden': self.head_hidden,
            'dropout': self.dropout,
            'learning_rate': self.learning_rate,
            'weight_decay': self.weight_decay,
            'pos_weight': self.pos_weight,
            'epochs': self.epochs,
            'batch_size': self.batch_size,
            'inference_batch': self.inference_batch,
            'patience': self.patience,
            'max_context': self.max_context,
            'in_dim': self.in_dim,
        }
        if extra:
            meta.update(extra)
        meta_path = os.path.join(model_dir, 'meta.json')
        with open(meta_path, 'w') as f:
            json.dump(meta, f, indent=2, default=str)
        return {'state': state_path, 'meta': meta_path}

### Integration notes (for claude_mode)
The TimesFM backbone is **loaded once and reused** for both encode passes (train + val) and again for inference — it never sees a backward pass, so memory pressure is just the 200M-param model in fp32 (~800MB) plus a small inference batch. The `inference_batch` HP is the TimesFM forward batch (CPU-friendly when GPU is busy with the head); separate from the head's training `batch_size`. The encoder normalizes inputs internally (`normalize_inputs=True`) but **assumes the channel you pick has roughly stationary scale** — `channel_index=-1` defaults to the last engineered feature, which by convention in `sequence_loader.py` tends to be a log-return-like column, but the sweep includes `0/1/2` as alternatives if the trailing column turns out to be a calendar or ID feature. `force_flip_invariance=True` is critical for finance: bear regimes look like bull regimes with a sign flip, and without it the model's pretrained positivity prior would systematically mis-rank W5. Expected gate behavior: largest expected lift on **W3 (bear-to-bull transition) and W6 (bear day, monotonic-prior window)** where the quantile-spread feature should fire as a regime-conditional confidence; W1 (bull) and W7 (post-pivot bull) should be roughly neutral vs. existing tabular trainers since pretrained models tend to under-react to clean trends. Do **not** lower pos_weight below 1.5 on the first run — the FreTS lesson in `feedback_torch_frets_low_posweight_collapses_scores.md` applies identically to this small head.
