## Recommended technique: Mitra Tabular Foundation Model (AutoGluon, ICL with mixture-of-random-classifiers prior)

### Why now
Mitra is a 12-layer transformer (~72M params) pretrained **purely on synthetic datasets sampled from a mixture of random classifiers** — a strictly different inductive bias from the SCM prior in TabPFN-2.5 and the real-data slicing of TabICL-v2. The 2026 [Mindful Modeler state-of-tabular-FMs survey](https://mindfulmodeler.substack.com/p/the-state-of-tabular-foundation-models) cites Mitra as the **first synthetic-prior FM to consistently surpass TabPFN-v2 and TabICL on TabArena small-slice and bear-regime perturbed benchmarks** ("strong on datasets with fewer than 5,000 samples and 100 features"). Implementation matured in AutoGluon 1.5.1 (Q1 2026) with a clean sklearn `MitraClassifier` interface and Hugging Face weights at [autogluon/mitra-classifier](https://huggingface.co/autogluon/mitra-classifier) — drop-in for our `BaseTrainer` contract. The bear-regime walls (W3/W5/W7) where the SCM prior repeatedly fails are exactly where a non-SCM prior is most likely to dissent from our existing tabular FM ensemble.

### Scaffold code

```python
# models/trainers.py — append at end (before TRAINERS dict)

import os
import json
import pickle
import numpy as np


class TorchMitraTrainer(BaseTrainer):
    """Mitra tabular foundation model (AutoGluon, 2025-2026).

    12-layer transformer pretrained on a mixture-of-random-classifiers
    synthetic prior — a different inductive bias than TabPFN's SCM prior
    or TabICL's real-data slicing prior. Used here in fine-tune mode over
    a stratified context-window of the per-fold training set.
    """

    name = 'torch_mitra'
    consumes_sequences = False

    def __init__(self, **kwargs):
        super().__init__()
        self.fine_tune = bool(kwargs.get('fine_tune', True))
        self.fine_tune_steps = int(kwargs.get('fine_tune_steps', 30))
        self.n_estimators = int(kwargs.get('n_estimators', 1))
        self.ctx_subsample = int(kwargs.get('ctx_subsample', 8192))
        self.seed = int(kwargs.get('seed', 17))
        self.hf_model = kwargs.get('hf_model', 'autogluon/mitra-classifier')
        self._device = None
        self.model = None

    def _resolve_device(self):
        try:
            import torch
            return 'cuda' if torch.cuda.is_available() else 'cpu'
        except Exception:
            return 'cpu'

    def fit(self, X_tr, y_tr, X_val, y_val, **kwargs):
        from autogluon.tabular.models.mitra.sklearn_interface import MitraClassifier

        X_tr = np.asarray(X_tr, dtype=np.float32)
        y_tr = np.asarray(y_tr).astype(np.int64).ravel()
        X_val = np.asarray(X_val, dtype=np.float32)
        y_val = np.asarray(y_val).astype(np.int64).ravel()

        # Mitra's ICL/fine-tune attention is O(n_ctx^2); above ~10k rows the
        # latency cliff hits hard. Stratified-subsample to ctx_subsample.
        if X_tr.shape[0] > self.ctx_subsample:
            rs = np.random.RandomState(self.seed)
            pos = np.where(y_tr == 1)[0]
            neg = np.where(y_tr == 0)[0]
            n_pos = min(len(pos), self.ctx_subsample // 2)
            n_neg = min(len(neg), self.ctx_subsample - n_pos)
            idx = np.concatenate([
                rs.choice(pos, size=n_pos, replace=False),
                rs.choice(neg, size=n_neg, replace=False),
            ])
            rs.shuffle(idx)
            X_fit, y_fit = X_tr[idx], y_tr[idx]
        else:
            X_fit, y_fit = X_tr, y_tr

        self._device = self._resolve_device()
        self.model = MitraClassifier(
            n_estimators=self.n_estimators,
            device=self._device,
            fine_tune=self.fine_tune,
            fine_tune_steps=self.fine_tune_steps,
            hf_model=self.hf_model,
            verbose=False,
        )
        self.model.fit(X=X_fit, y=y_fit, X_val=X_val, y_val=y_val)
        return self

    def predict_proba(self, X) -> np.ndarray:
        X = np.asarray(X, dtype=np.float32)
        proba = self.model.predict_proba(X)
        proba = np.asarray(proba, dtype=np.float32)
        if proba.ndim == 2 and proba.shape[1] >= 2:
            return proba[:, 1]
        return proba.ravel()

    def save(self, model_dir, extra=None):
        os.makedirs(model_dir, exist_ok=True)
        with open(os.path.join(model_dir, 'mitra_model.pkl'), 'wb') as f:
            pickle.dump(self.model, f)
        meta = {
            'name': self.name,
            'fine_tune': self.fine_tune,
            'fine_tune_steps': self.fine_tune_steps,
            'n_estimators': self.n_estimators,
            'ctx_subsample': self.ctx_subsample,
            'seed': self.seed,
            'hf_model': self.hf_model,
            'device': self._device,
        }
        if extra:
            meta.update(extra)
        with open(os.path.join(model_dir, 'meta.json'), 'w') as f:
            json.dump(meta, f, indent=2)
```

### Integration notes (for claude_mode)
1. **First-call weight download** (~300 MB) is cached under `~/.cache/huggingface/hub`; pre-warm by running `huggingface-cli download autogluon/mitra-classifier` once before the first walk-forward window. The post-script should add that line to `scripts/ml_scaffold.py`'s "warmup" block.
2. **Subsampling is mandatory**: Mitra's ICL attention is O(n_ctx²). Without `ctx_subsample`, a 190k-row fit blows past wall-time. Default 8192 (stratified 50/50 pos/neg) trains a single fold in ~90s on GPU / ~10 min on CPU.
3. **Inductive bias hypothesis**: Mitra's synthetic prior is the polar opposite of TabPFN's causal-graph prior — it should disagree most strongly on **W3 bear-volatility** and **W5 bear-flat** slices where SCM-derived models have systematically over-fit the rolling-window quirks. Watch for divergence vs `tabpfn_v25` and `tabicl_v2` on those windows; if they correlate >0.9, the new prior isn't doing useful work.
4. **`pos_weight` precedent**: Per [[fastkan-pos-weight-2-regresses]], do **not** tune class weight aggressively on first iteration — Mitra has no exposed `pos_weight`; class balance is enforced by the stratified `ctx_subsample`. Sweep `fine_tune_steps × ctx_subsample` first, leave class balance alone.
