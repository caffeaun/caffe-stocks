# Research brief — 2026-06-04

## Registry-bias diagnosis
Last 30-day iteration split: other=781 (39%), xgb_classifier=455 (23%), nn=201 (10%), ranker=190 (9%), linear_kernel=188 (9%), xgb_regressor=111 (6%), non_parametric=66 (3%), tree_other=16 (1%). GBDT-loss and small-MLP heads together absorb 70%+ of recent compute; the NN bucket itself is dominated by the *flat-quantile* TS foundation-model recipe (`torch_timesfm`, `torch_toto2`, `torch_ttm`, `torch_chronos2`, `torch_sundial`, `torch_mantis`, `torch_time_moe`). What is structurally missing is a **decoder-only TS foundation model with a multi-token quantile prediction head** — i.e. a quantile decoder that emits *one head per quantile per horizon step* rather than a flat per-step distribution. That is the inductive-bias slot that broke W1/W5 walls for TimesFM ([[timesfm-breaks-w1-w5]]), W4 for Toto-2.0 ([[toto2-breaks-w4-alive-w2]]), and W6 fat-tail for FastKAN ([[fastkan-first-shot]]) — Moirai-2.0 brings a structurally distinct quantile-decoder bias to that exact recipe, orthogonal to yesterday's pick TabDPT v1.1 (2D tabular retrieval ICL).

## Recommended technique: Moirai-2.0 (Salesforce decoder-only TS foundation model with multi-token quantile head)

### Why now
Salesforce shipped Moirai-2.0 in August 2025 as a *decoder-only* successor to the Moirai-1.x encoder-decoder line, with the central architectural change being a **multi-token quantile prediction head** (9 quantiles 0.1..0.9 emitted per horizon step, vs the flat single-distribution head in TimesFM-2.5 and the factorized-attention head in Toto-2.0): the Salesforce blog reports SOTA MASE on GIFT-Eval among non-leaking models with *2× faster* inference and *30× smaller* footprint than Moirai-1.0-Large ([Salesforce blog](https://www.salesforce.com/blog/moirai-2-0/), [Moirai-2.0 HF model card](https://huggingface.co/Salesforce/moirai-2.0-R-small)). The `uni2ts==2.0.0` release on PyPI (Nov 2025) ships the `Moirai2Module` / `Moirai2Forecast` Python API with Apache-2.0 weights auto-downloaded from `Salesforce/moirai-2.0-R-small` ([uni2ts on PyPI](https://pypi.org/project/uni2ts/), [DeepWiki Moirai2 documentation](https://deepwiki.com/SalesforceAIResearch/uni2ts/2.3-moirai2-models)), making the frozen-encoder + tiny-MLP-head pattern that worked for TimesFM / Toto-2.0 / TTM directly reusable. Because the multi-token head produces a *smoother across-horizon* quantile distribution than TimesFM's flat head, this is the most plausible structural lever to crack the W3 bear-regime indecision window where every prior TS-FM scaffold has score-collapsed.

# models/trainers.py — append at end (before TRAINERS dict)
import os
import json
import math
from pathlib import Path

import numpy as np

try:
    import torch
    import torch.nn as nn
    import torch.optim as optim
    _HAS_TORCH_MOIRAI2 = True
except Exception:
    _HAS_TORCH_MOIRAI2 = False

try:
    from uni2ts.model.moirai2 import Moirai2Forecast, Moirai2Module
    _HAS_MOIRAI2 = True
except Exception:
    _HAS_MOIRAI2 = False


# Module-level singleton cache — Moirai-2.0 weights are ~150 MB; share across
# all 7 walk-forward gate windows + HP sweeps. Keyed by (model_id, ctx, hor).
_MOIRAI2_CACHE: dict = {}


class _Moirai2Head(nn.Module):
    """Tiny MLP head over (quantiles + last-row tabular + per-channel stats)."""

    def __init__(self, in_dim: int, hidden: int, dropout: float):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, hidden),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(hidden, hidden // 2),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(hidden // 2, 1),
        )

    def forward(self, x):
        return self.net(x).squeeze(-1)


class TorchMoirai2Trainer(BaseTrainer):
    """Frozen Salesforce Moirai-2.0 backbone -> MLP classifier head.

    Decoder-only causal-attention TS foundation model with a *multi-token
    quantile prediction head* (9 quantiles 0.1..0.9 over horizon H), trained
    on the LOTSA-v2 mixture. We freeze the backbone, run the model on one (or
    a curated subset of) channel from the (N, L=20, F=96) sequence window,
    extract per-quantile per-horizon-step forecast features, concatenate with
    the last raw row + cheap per-channel sequence stats, train a small MLP
    head with BCEWithLogitsLoss + pos_weight on the 7-window walk-forward
    gate. Slot-complement: TimesFM = patched-decoder + cross-token quantile
    head; Toto-2.0 = factorized attention; Moirai-2.0 = causal decoder-only
    with multi-token quantile head (none of the three share that combo).
    """

    name = 'torch_moirai2'
    consumes_sequences = True

    # Default curated continuous channels (mirrors torch_toto2 / torch_mantis
    # picks: ret_1d, ret_5d, atr_pct, vol_ratio, rsi_14, macd_hist, set_ret_5d_z60).
    _DEFAULT_CHANNELS = (0, 1, 3, 4, 10, 11, 24)

    def __init__(self,
                 model_id: str = 'Salesforce/moirai-2.0-R-small',
                 context_length: int = 512,
                 prediction_length: int = 64,
                 patch_size: int = 16,
                 num_samples: int = 100,
                 channel_indices=None,
                 head_hidden: int = 128,
                 dropout: float = 0.15,
                 learning_rate: float = 1e-3,
                 weight_decay: float = 1e-4,
                 pos_weight: float = 1.5,
                 epochs: int = 25,
                 batch_size: int = 256,
                 inference_batch: int = 64,
                 patience: int = 5,
                 grad_clip: float = 1.0,
                 use_pretrained: bool = True,
                 include_last_row: bool = True,
                 use_seq_stats: bool = True,
                 max_train_rows: int = 60000,
                 device: str = None,
                 random_state: int = 42,
                 **_):
        if not _HAS_TORCH_MOIRAI2:
            raise ImportError(
                "torch not available. `pip install torch>=2.6`."
            )
        if not _HAS_MOIRAI2:
            raise ImportError(
                "uni2ts not installed. `pip install uni2ts==2.0.0 gluonts "
                "huggingface-hub` (Python >=3.10)."
            )
        self.model_id = str(model_id)
        self.context_length = int(context_length)
        self.prediction_length = int(prediction_length)
        self.patch_size = int(patch_size)
        self.num_samples = int(num_samples)
        if channel_indices is None or len(channel_indices) == 0:
            self.channel_indices = None
        else:
            self.channel_indices = [int(c) for c in channel_indices]
        self.head_hidden = int(head_hidden)
        self.dropout = float(dropout)
        self.learning_rate = float(learning_rate)
        self.weight_decay = float(weight_decay)
        self.pos_weight = float(pos_weight)
        self.epochs = int(epochs)
        self.batch_size = int(batch_size)
        self.inference_batch = int(inference_batch)
        self.patience = int(patience)
        self.grad_clip = float(grad_clip)
        self.use_pretrained = bool(use_pretrained)
        self.include_last_row = bool(include_last_row)
        self.use_seq_stats = bool(use_seq_stats)
        self.max_train_rows = int(max_train_rows)
        self.requested_device = device
        self.random_state = int(random_state)
        self._head = None
        self._scaler_mean = None
        self._scaler_std = None
        self._chan_mean = None
        self._chan_std = None
        self._in_dim = None
        self._device = None
        self._num_channels_used = None

    # ---------- device / sanitization ----------
    def _pick_device(self):
        if self.requested_device:
            return self.requested_device
        if not torch.cuda.is_available():
            return 'cpu'
        best_idx, best_free = 0, -1
        for i in range(torch.cuda.device_count()):
            try:
                free, _ = torch.cuda.mem_get_info(i)
            except Exception:
                free = 0
            if free > best_free:
                best_free, best_idx = free, i
        return f'cuda:{best_idx}'

    def _sanitize(self, X):
        return np.nan_to_num(np.asarray(X, dtype=np.float32),
                              nan=0.0, posinf=0.0, neginf=0.0)

    def _stratified_subsample(self, X_3d, y):
        n = len(X_3d)
        if n <= self.max_train_rows:
            return X_3d, y
        rng = np.random.default_rng(self.random_state)
        pos_idx = np.where(y == 1)[0]
        neg_idx = np.where(y == 0)[0]
        frac = self.max_train_rows / float(n)
        n_pos = max(1, int(round(len(pos_idx) * frac)))
        n_neg = max(1, min(self.max_train_rows - n_pos, len(neg_idx)))
        sel_pos = rng.choice(pos_idx, size=n_pos, replace=False)
        sel_neg = rng.choice(neg_idx, size=n_neg, replace=False)
        idx = np.concatenate([sel_pos, sel_neg])
        rng.shuffle(idx)
        return X_3d[idx], y[idx]

    # ---------- channel selection / scaling ----------
    def _select_channels(self, X_3d):
        N, L, F = X_3d.shape
        if self.channel_indices is None:
            idx = [c for c in self._DEFAULT_CHANNELS if c < F]
            if not idx:
                idx = list(range(min(F, 7)))
        else:
            idx = [c if c >= 0 else (F + c) for c in self.channel_indices]
            idx = [max(0, min(int(c), F - 1)) for c in idx]
        return X_3d[:, :, idx].astype(np.float32)

    def _fit_channel_scaler(self, X_sel):
        flat = X_sel.reshape(-1, X_sel.shape[2])
        self._chan_mean = flat.mean(axis=0).astype(np.float32)
        self._chan_std = (flat.std(axis=0) + 1e-6).astype(np.float32)

    def _apply_channel_scaler(self, X_sel):
        return ((X_sel - self._chan_mean) / self._chan_std).astype(np.float32)

    def _pad_context(self, X_sel):
        """Left-zero-pad the L axis up to context_length. (N, L, C) -> (N, ctx, C)."""
        N, L, C = X_sel.shape
        target = self.context_length
        if L == target:
            return X_sel, L
        if L > target:
            return X_sel[:, -target:, :], target
        pad = np.zeros((N, target - L, C), dtype=np.float32)
        return np.concatenate([pad, X_sel], axis=1), L

    # ---------- backbone load (cached singleton) ----------
    def _load_backbone(self):
        key = (self.model_id, self.context_length, self.prediction_length,
               self.patch_size, self.use_pretrained)
        if key in _MOIRAI2_CACHE:
            forecaster = _MOIRAI2_CACHE[key]
            self._device = next(forecaster.module.parameters()).device
            return forecaster

        module = Moirai2Module.from_pretrained(self.model_id)
        if not self.use_pretrained:
            # Re-init weights for ablation
            for p in module.parameters():
                if p.dim() > 1:
                    nn.init.xavier_uniform_(p)
                else:
                    nn.init.zeros_(p)

        forecaster = Moirai2Forecast(
            module=module,
            prediction_length=self.prediction_length,
            context_length=self.context_length,
            patch_size=self.patch_size,
            num_samples=self.num_samples,
            target_dim=1,
            feat_dynamic_real_dim=0,
            past_feat_dynamic_real_dim=0,
        )
        forecaster.module.eval()
        for p in forecaster.module.parameters():
            p.requires_grad_(False)
        device = self._pick_device()
        forecaster.module.to(device)
        _MOIRAI2_CACHE[key] = forecaster
        self._device = torch.device(device) if isinstance(device, str) else device
        return forecaster

    # ---------- forecast feature extraction ----------
    def _encode(self, X_3d):
        """For each row and each selected channel, run Moirai-2.0 forecast and
        gather per-quantile per-horizon statistics. Output shape:
        (N, C * (5 + 2*Q)) where Q = number of quantile levels (9).
        Stats per channel: mean, std, last_step, slope (last-first),
        delta-vs-last-obs (mean of horizon - last_obs) + Q*(per-q first step)
        + Q*(per-q last step). Cheap; the head learns which slot matters.
        """
        X_sel = self._select_channels(X_3d)
        X_sel = self._sanitize(X_sel)
        X_sel = self._apply_channel_scaler(X_sel)
        X_padded, _real_len = self._pad_context(X_sel)
        N, L, C = X_padded.shape
        self._num_channels_used = C

        forecaster = self._load_backbone()
        device = self._device
        bs = max(1, self.inference_batch)
        feats = []
        # Moirai-2.0 is univariate per-channel: loop channels, batch rows.
        # forecaster.module accepts a (B, L) target with observed_mask;
        # we mirror the GluonTS path with a direct tensor call for speed.
        with torch.no_grad():
            for ch in range(C):
                series = X_padded[:, :, ch]  # (N, L)
                ch_chunks = []
                for i in range(0, N, bs):
                    j = min(N, i + bs)
                    target = torch.from_numpy(series[i:j]).to(device)  # (B, L)
                    target = target.unsqueeze(-1)                       # (B, L, 1)
                    observed_mask = torch.ones_like(target, dtype=torch.bool)
                    # Moirai2Module.forward returns quantile preds; the
                    # convenience path is `forecaster.module.sample` -> samples,
                    # but the deterministic quantile head is the multi-token
                    # output we want.
                    q = forecaster.module(
                        target=target,
                        observed_mask=observed_mask,
                        sample_id=torch.zeros(target.shape[:2], dtype=torch.long, device=device),
                        time_id=torch.arange(target.shape[1], device=device)
                            .unsqueeze(0).expand(target.shape[0], -1),
                        variate_id=torch.zeros(target.shape[:2], dtype=torch.long, device=device),
                        prediction_mask=torch.zeros(target.shape[:2], dtype=torch.bool, device=device),
                        patch_size=torch.full((target.shape[0],), self.patch_size,
                                              dtype=torch.long, device=device),
                    )
                    # q shape: (B, H, Q=9) — multi-token quantile output
                    if q.dim() == 4:
                        q = q.squeeze(-1)
                    Q = q.shape[-1]
                    feat_mean = q.mean(dim=-1)              # (B, H)
                    feat_std = q.std(dim=-1) + 1e-6
                    last_obs = target[:, -1, :].expand(-1, q.shape[1])  # (B, H)
                    delta = (feat_mean - last_obs).mean(dim=-1, keepdim=True)  # (B,1)
                    slope = (feat_mean[:, -1] - feat_mean[:, 0]).unsqueeze(-1)  # (B,1)
                    last_step = feat_mean[:, -1:]                           # (B,1)
                    first_step = feat_mean[:, :1]                           # (B,1)
                    std_pool = feat_std.mean(dim=-1, keepdim=True)          # (B,1)
                    q_first = q[:, 0, :]                                    # (B,Q)
                    q_last = q[:, -1, :]                                    # (B,Q)
                    blk = torch.cat([delta, slope, last_step, first_step,
                                     std_pool, q_first, q_last], dim=-1)  # (B, 5+2Q)
                    ch_chunks.append(blk.cpu().numpy().astype(np.float32))
                feats.append(np.concatenate(ch_chunks, axis=0))
        # stack channel features: (N, C * (5+2Q))
        return np.concatenate(feats, axis=1).astype(np.float32)

    def _stack_features(self, X_3d, emb):
        emb = self._sanitize(emb)
        parts = [emb]
        if self.include_last_row:
            last = self._sanitize(X_3d[:, -1, :])
            parts.append(last)
        if self.use_seq_stats:
            N, L, F = X_3d.shape
            seq = self._sanitize(X_3d)
            stats = np.concatenate([
                seq.mean(axis=1), seq.std(axis=1),
                seq.min(axis=1), seq.max(axis=1),
                (seq[:, -1, :] - seq[:, 0, :]),
            ], axis=1).astype(np.float32)
            parts.append(stats)
        return np.concatenate(parts, axis=1)

    def _fit_scaler(self, Fmat):
        self._scaler_mean = Fmat.mean(axis=0).astype(np.float32)
        self._scaler_std = (Fmat.std(axis=0) + 1e-6).astype(np.float32)

    def _apply_scaler(self, Fmat):
        return ((Fmat - self._scaler_mean) / self._scaler_std).astype(np.float32)

    # ---------- fit / predict / save ----------
    def fit(self, X_tr, y_tr, X_val=None, y_val=None, verbose: bool = False,
            pnl_train=None, pnl_val=None, dates_train=None, dates_val=None):
        X_tr_3d = self._sanitize(X_tr)
        if X_tr_3d.ndim != 3:
            raise ValueError(
                f'torch_moirai2 expects 3D sequence input (N, L, F); '
                f'got shape {X_tr_3d.shape}.')
        y_tr_arr = np.asarray(y_tr, dtype=np.float32).ravel()
        X_tr_3d, y_tr_arr = self._stratified_subsample(X_tr_3d, y_tr_arr)

        torch.manual_seed(self.random_state)
        np.random.seed(self.random_state)

        X_sel_tr = self._select_channels(X_tr_3d)
        X_sel_tr = self._sanitize(X_sel_tr)
        self._fit_channel_scaler(X_sel_tr)

        emb_tr = self._encode(X_tr_3d)
        F_tr = self._stack_features(X_tr_3d, emb_tr)
        self._fit_scaler(F_tr)
        F_tr = self._apply_scaler(F_tr)
        self._in_dim = int(F_tr.shape[1])

        has_val = (X_val is not None) and (y_val is not None) and len(y_val) > 0
        if has_val:
            X_val_3d = self._sanitize(X_val)
            emb_val = self._encode(X_val_3d)
            F_val = self._apply_scaler(self._stack_features(X_val_3d, emb_val))
            y_val_arr = np.asarray(y_val, dtype=np.float32).ravel()
        else:
            F_val = None

        device = self._device or self._pick_device()
        self._head = _Moirai2Head(self._in_dim, self.head_hidden, self.dropout).to(device)
        pos_w = torch.tensor([self.pos_weight], device=device)
        loss_fn = nn.BCEWithLogitsLoss(pos_weight=pos_w)
        opt = optim.AdamW(self._head.parameters(),
                          lr=self.learning_rate,
                          weight_decay=self.weight_decay)

        F_tr_t = torch.from_numpy(F_tr).to(device)
        y_tr_t = torch.from_numpy(y_tr_arr).to(device)
        if has_val:
            F_val_t = torch.from_numpy(F_val).to(device)
            y_val_t = torch.from_numpy(y_val_arr).to(device)

        best_val = float('inf')
        best_state = None
        bad = 0
        N = F_tr_t.size(0)
        for _ep in range(self.epochs):
            self._head.train()
            perm = torch.randperm(N, device=device)
            for i in range(0, N, self.batch_size):
                idx = perm[i:i + self.batch_size]
                logit = self._head(F_tr_t[idx])
                loss = loss_fn(logit, y_tr_t[idx])
                opt.zero_grad()
                loss.backward()
                if self.grad_clip > 0:
                    torch.nn.utils.clip_grad_norm_(
                        self._head.parameters(), self.grad_clip)
                opt.step()
            if has_val:
                self._head.eval()
                with torch.no_grad():
                    vloss = loss_fn(self._head(F_val_t), y_val_t).item()
                if vloss < best_val - 1e-4:
                    best_val = vloss
                    best_state = {k: v.detach().cpu().clone()
                                  for k, v in self._head.state_dict().items()}
                    bad = 0
                else:
                    bad += 1
                    if bad >= self.patience:
                        break
        if best_state is not None:
            self._head.load_state_dict(best_state)
        self._head.eval()
        return self

    def predict_proba(self, X) -> np.ndarray:
        if self._head is None:
            raise RuntimeError('TorchMoirai2Trainer.predict_proba before fit')
        X_3d = self._sanitize(X)
        if X_3d.ndim != 3:
            raise ValueError(
                f'torch_moirai2.predict_proba expects 3D input (N, L, F); '
                f'got shape {X_3d.shape}.')
        emb = self._encode(X_3d)
        Fmat = self._apply_scaler(self._stack_features(X_3d, emb))
        device = self._device or self._pick_device()
        out = []
        self._head.eval()
        bs = max(self.batch_size, 1)
        with torch.no_grad():
            for i in range(0, Fmat.shape[0], bs):
                xb = torch.from_numpy(Fmat[i:i + bs]).to(device)
                p = torch.sigmoid(self._head(xb)).cpu().numpy().astype(np.float32)
                out.append(p)
        return np.concatenate(out, axis=0).astype(np.float32)

    @property
    def hyperparams(self):
        return dict(
            model_id=self.model_id,
            context_length=self.context_length,
            prediction_length=self.prediction_length,
            patch_size=self.patch_size,
            num_samples=self.num_samples,
            channel_indices=self.channel_indices,
            head_hidden=self.head_hidden,
            dropout=self.dropout,
            learning_rate=self.learning_rate,
            weight_decay=self.weight_decay,
            pos_weight=self.pos_weight,
            epochs=self.epochs,
            batch_size=self.batch_size,
            inference_batch=self.inference_batch,
            patience=self.patience,
            grad_clip=self.grad_clip,
            use_pretrained=self.use_pretrained,
            include_last_row=self.include_last_row,
            use_seq_stats=self.use_seq_stats,
            max_train_rows=self.max_train_rows,
            random_state=self.random_state,
        )

    def save(self, model_dir, extra=None):
        out = Path(model_dir)
        out.mkdir(parents=True, exist_ok=True)
        torch.save({
            'head_state_dict': self._head.state_dict() if self._head is not None else None,
            'scaler_mean': self._scaler_mean,
            'scaler_std': self._scaler_std,
            'chan_mean': self._chan_mean,
            'chan_std': self._chan_std,
            'in_dim': self._in_dim,
            'num_channels_used': self._num_channels_used,
            'hparams': self.hyperparams,
        }, out / 'model.pt')
        meta = {'trainer': self.name, 'device': str(self._device),
                'in_dim': self._in_dim,
                'num_channels_used': self._num_channels_used,
                'hparams': self.hyperparams}
        if extra:
            meta.update(extra)
        with open(out / 'meta.json', 'w') as f:
            json.dump(meta, f, indent=2, default=str)
        return {'model_pt': str(out / 'model.pt'),
                'meta': str(out / 'meta.json')}

### Integration notes (for claude_mode)
`torch_moirai2` is a sequence-consumer (`consumes_sequences = True`) — claude_mode must pass 3D `(N, L=20, F=96)` tensors via the same path already used by `torch_toto2` / `torch_timesfm` / `torch_mantis`; do not flatten upstream. The backbone load is the dominant cold cost (~8-12s) and is cached at module level by `(model_id, ctx, hor, patch, pretrained)` so subsequent windows + HP sweeps are free; wall-time per gate window is ~3-5 min on a single GPU at `inference_batch=64`. Pin `pos_weight ≤ 1.5` per [[timesfm-pos-weight-2-regresses]] — Moirai's multi-token quantile head will exhibit the same lock-step logit inflation if pushed higher, and per [[toto2-horizon96-regresses]] do **NOT** sweep `(context_length, prediction_length, patch_size)` jointly with head HPs in train mode — pin the encoder triple and rotate orthogonal axes. py3.14 install: `uni2ts==2.0.0` declares `python>=3.10`; if the wheel resolution fails, the post-script's `--ignore-requires-python` retry layer should handle it the same way it did for `torch_ttm` ([[ttm-default-w7-only]]) and `torch_toto2` ([[toto2-breaks-w4-alive-w2]]). Per [[no-sudo]] do not attempt `apt-get install` for any missing build-deps; the user installs system packages themselves.
